Подбор по параметрам арматуры

Электропривод выбирается по типу арматуры, моменту, напряжению, режиму работы, сигналам управления и условиям эксплуатации.

Для задвижек

Многооборотные решения для управления задвижками.

Для кранов и затворов

Неполноповоротные исполнения для шаровых кранов и дисковых затворов.

Для автоматизации

Исполнения с сигналами управления, обратной связью и дополнительными опциями.

Для заявки нужны

  • тип и размер арматуры;
  • момент или усилие;
  • напряжение питания;
  • режим управления;
  • условия эксплуатации;
  • модель старого привода.
