Исполнительный механизм подбирается по типу арматуры, моменту, управлению, условиям среды и требованиям автоматизации.

Электроприводы

Для дистанционного управления запорной и регулирующей арматурой.

Пневмоприводы

Для быстрого управления арматурой в автоматизированных системах.

Комплектующие

Позиционеры, блоки концевых выключателей, переходные элементы и узлы подключения.

Для заявки укажите

  • тип арматуры;
  • требуемый момент или усилие;
  • управляющий сигнал;
  • напряжение питания;
  • условия эксплуатации;
  • модель старого привода.
