Подбор по задаче управления

Пневмопривод выбирается по типу арматуры, моменту, давлению управляющего воздуха, схеме действия и требованиям автоматизации.

Двойного действия

Для управления арматурой при подаче воздуха в обе полости привода.

С пружинным возвратом

Для задач с заданным безопасным положением при потере воздуха.

С комплектующими

Позиционеры, блоки концевых выключателей, клапаны управления и монтажные элементы.

Для заявки укажите

  • тип арматуры;
  • требуемый момент;
  • давление воздуха;
  • схему действия;
  • управление и сигнализацию;
  • условия эксплуатации.
