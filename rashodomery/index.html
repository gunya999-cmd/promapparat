Какие задачи закрываем

Поставка приборов для учёта, контроля и автоматизации технологических процессов.

Жидкости

Подбор по вязкости, температуре, давлению, материалу и точности измерения.

Газ

Приборы для технологических газов с учётом диапазона расхода и условий эксплуатации.

Пар

Решения для измерения расхода пара на промышленных объектах.

Для подбора укажите

  • тип среды и состояние среды;
  • минимальный, рабочий и максимальный расход;
  • давление и температуру;
  • DN, тип присоединения;
  • требуемый выходной сигнал и питание.
