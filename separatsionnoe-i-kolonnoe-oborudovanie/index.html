Раздел сохранён для заявок по старому каталогу, комплексной комплектации объектов и поисковых запросов по технологическим аппаратам.

Факельные сепараторы

Аппараты для технологических систем, где требуется отделение жидкой фазы и защита оборудования.

Сепараторы нефтегазовые

Оборудование для разделения нефтегазовых сред по параметрам технологического процесса.

Газовые сепараторы

Решения для подготовки, очистки и защиты оборудования на газовых линиях.

Колонные аппараты

Аппараты колонного типа по чертежам, ТЗ и проектной документации.

Материальное исполнение

Подбор материалов под среду, температуру, давление и требования промышленного объекта.

Документация

Паспорта, сертификаты, требования к испытаниям и комплектность согласуются по проекту.
