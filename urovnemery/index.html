Каталог ГК «УЛЬТРА»

Уровнемеры и сигнализаторы уровня

Раздел заполнен только позициями из каталога ГК «УЛЬТРА»: радарные, рефлекс‑радарные, байпасные, буйковые, магнитострикционные уровнемеры и вибрационные сигнализаторы уровня.

Запросить КПРасходомеры

Карточки уровнемеров

Номенклатура соответствует брошюре ГК «УЛЬТРА».

Радарный уровнемер RRF5

Для жидкостей и сыпучих материалов в сложных условиях.

  • Диапазон 100–120000 мм
  • Давление до 32 МПа
  • Температура среды −60…+650 °C
  • Погрешность ±1 / ±2 / ±3 / ±6 / ±12 мм
  • 4–20 мА + HART, RS485 Modbus

Рефлекс‑радарный уровнемер RRF2

TDR‑измерение уровня при высокой температуре и давлении.

  • Диапазон 300–30000 мм
  • Давление до 40 МПа
  • Температура среды −60…+400 °C
  • Погрешность ±3 мм
  • 4–20 мА + HART, RS485, Foundation Fieldbus

Рефлекс‑радарный уровнемер

Позиция из каталога ГК «УЛЬТРА» для непрерывного контроля уровня.

  • Для резервуаров и технологических емкостей
  • Для жидких сред
  • Подбор по диапазону, давлению, температуре и типу присоединения
  • Комплектация под требования объекта

Байпасный уровнемер ВМ26

Байпасный уровнемер для визуального и приборного контроля уровня.

  • Для жидкостей в емкостях и аппаратах
  • Байпасная камера
  • Подбор по давлению, температуре и материалу
  • Возможна комплектация сигнализацией и датчиками

Буйковый уровнемер

Буйковый уровнемер для измерения уровня жидкости.

  • Для жидких сред
  • Подбор по плотности, давлению и температуре
  • Исполнения под параметры объекта
  • Применение в технологических емкостях и аппаратах

Магнитострикционный уровнемер FJM‑L

Уровнемер для непрерывного измерения уровня жидкости.

  • Для резервуаров и технологических емкостей
  • Подбор по диапазону измерений
  • Исполнения под рабочую среду и условия эксплуатации
  • Выходные сигналы и исполнение уточняются по задаче

Вибрационный сигнализатор уровня FPS

Сигнализация предельного уровня.

  • Среда: жидкость и сыпучие вещества
  • Длина вилки 63–3000 мм
  • Давление до 6,3 МПа
  • Температура среды −60…+200 °C
  • DPDT, SPST, PNP/NPN; Ex d, Ex i, Ex t

Для подбора уровнемера

Укажите среду, диапазон измерения, высоту резервуара, давление, температуру, плотность, наличие пены/пара/пыли, тип присоединения, питание, выходной сигнал и требования к взрывозащите.
