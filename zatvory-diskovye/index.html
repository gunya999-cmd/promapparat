Запорная арматура

Дисковые затворы для промышленных трубопроводов

Подбор и поставка дисковых затворов для технологических линий, узлов обвязки, ремонтных заявок и проектной комплектации.

Запросить КПОпросный лист

Основные исполнения

Затвор подбирается по среде, давлению, температуре, типу присоединения и управлению.

Межфланцевые

Компактные решения для установки между фланцами трубопровода.

Фланцевые

Исполнения для промышленных трубопроводов и технологических узлов.

С приводом

Ручные, редукторные, электрические и пневматические варианты управления.

Для подбора нужны

  • DN, PN;
  • тип присоединения;
  • среда и температура;
  • материал корпуса и седла;
  • тип управления;
  • комплект документов.
