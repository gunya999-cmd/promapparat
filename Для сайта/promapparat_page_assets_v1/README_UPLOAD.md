# Promapparat homepage assets package v1

Загружать в корень репозитория так, чтобы папка `assets/` оказалась в корне проекта.

## Что внутри

- `assets/logo/` — SVG-логотипы.
- `assets/hero/` — ассеты первого экрана.
- `assets/catalog/` — WebP-рендеры карточек каталога.
- `assets/spec/` — чертёж для блока спецификации.
- `assets/icons/` — SVG-иконки для шапки, hero, статистики, преимуществ и футера.
- `assets/css/components.css` — редактируемые CSS-компоненты кнопок/карточек.
- `assets/renders/` — совместимые имена под текущий `index.html`, чтобы ничего не ломалось.

## Важно

Кнопки, белые карточки, тени, рамки, скругления и фоновые плашки НЕ сделаны картинками.
Они должны оставаться CSS — так сайт быстрее и проще редактировать.

## Быстрая загрузка в GitHub

1. Открой репозиторий.
2. Загрузи папку `assets/` из архива с сохранением структуры.
3. После загрузки ассетов можно собирать `index.html` заново по этим путям.
